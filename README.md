# Sky Guide — SkyBlock трекер на русском

**[sky-guide.ru](https://sky-guide.ru)** — русскоязычный сайт-помощник по Hypixel SkyBlock. Вводишь ник Minecraft, и сайт показывает твой профиль, разбирает его и подсказывает, что делать дальше: что качать, что купить или скрафтить, как заработать монеты из того, что уже есть. Без регистрации и паролей.

![Главная страница sky-guide.ru](docs/img/landing.png)

## Для кого

- Для русскоязычных игроков SkyBlock, которым тяжело разбираться в английской вики и десятке разных сайтов.
- Для новичков: сайт по шагам ведёт от первых часов до Dungeons, Slayers и дорогого снаряжения.
- Для опытных: цены Bazaar и аукциона, заработок на флипах и крафтах, сравнение с друзьями, рейтинг.

Игровые термины (скиллы, предметы, статы, острова, меню) написаны по-английски, как в игре, а пояснения и советы по-русски.
Наведи на термин, и появится подсказка, что это и где взять.

## Что умеет

**Мой профиль**

- **Обзор** — сводка профиля: уровень, Networth, скиллы, главное, на что обратить внимание сейчас.
- **Что делать** — личный план прогрессии: шаги по порядку с объяснением, зачем каждый нужен и сколько стоит.
  Обновляется сам, пока играешь; ненужные шаги можно скрыть.
- **Прогресс** — скиллы (включая overflow-уровни), Catacombs, Slayers, HOTM и сколько осталось до следующей цели.
- **Снаряжение** — броня, оружие, инструменты с иконками, чарами и reforge; что улучшить в первую очередь.
- **Аксессуары** — Accessory Bag, Magical Power, каких аксессуаров не хватает и какие выгоднее всего докупить.
- **Питомцы, Музей, Запасы, Коллекции, Миньоны** — что есть, чего не хватает, Essence, Sacks, слоты миньонов.

**Справочник**

- **Заработок** — способы заработать из того, что у тебя уже есть: флипы Bazaar, крафты, фарм, Dungeons, с расчётом
  дохода в час по живым ценам.
- **Рынок** — цены Bazaar и аукциона с графиками и историей, поиск по-русски и по-английски.
- **Вики** — карточки ~9000 предметов: где взять, рецепт, цена, описание на русском.
- **Гайды** — гайды по скиллам, островам и этапам игры со ссылками на источники.
- **События** — календарь SkyBlock: мэры, ивенты, Jacob's Farming Contest.
- **Новости** — что нового на сайте.

**Игроки**

- **Сравнение** — до 4 профилей рядом.
- **Рейтинг** — богатство, уровень, Catacombs, Slayers среди профилей, которые открывали на сайте.

Работает на компьютере и телефоне. Данные профиля обновляются примерно раз в минуту, цены — непрерывно.

## Код

```
npm install && npm run dev               # http://localhost:5173, /api — на сервер :3000 (см. CONTRIBUTING.md)
SKY_API=https://sky-guide.ru npm run dev  # то же, но данные с живого сайта: сервер у себя поднимать не нужно
npm run build                           # dist/
docker build -t sky-guide-web .         # образ: только собранные файлы (как его запускают — в репо deploy)
```

Страницы — `src/pages/`, список разделов — `PAGES` в `src/App.jsx`, нижнее меню — `src/components/BottomNav.jsx`, текст с подсказками — `src/guides/Rich.jsx`.

## Репо проекта

| Репо | Что там |
|---|---|
| [core](https://github.com/sky-guide-ru/core) | расчёты без HTTP: разбор профиля, план «Что делать», рынок, гайды, русская база предметов, переводы. Пакет `@sky-guide/core` |
| [api](https://github.com/sky-guide-ru/api) | сервер: адреса `/api/*`, вход и аккаунты, SEO-страницы, OpenAPI и Swagger |
| [web](https://github.com/sky-guide-ru/web) | сайт [sky-guide.ru](https://sky-guide.ru) на React + Vite, данные берёт только у api |
| [deploy](https://github.com/sky-guide-ru/deploy) | запуск на сервере: Docker, Caddy, автообновление, бэкапы, браузерный e2e |
